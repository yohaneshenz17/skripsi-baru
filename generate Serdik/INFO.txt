🔧 PERSYARATAN:

• RAM 4GB (8GB recommended untuk batch besar)
• Koneksi internet (hanya untuk instalasi pertama)

═══════════════════════════════════════════════════════════════

💡 WORKFLOW PENGGUNAAN:

1. Upload Blanko Sertifikat (background)
2. Upload PDF dari UKMPPG (batch/multiple files)
3. Upload Tanda Tangan (Ketua & Kaprodi) 
4. Upload QR Code Segel Elektronik (2 files)
5. Input Nomor Seri Awal (7 digit)
6. Klik "Upload Semua File"
7. Klik "Generate Sertifikat"
8. Download Semua (ZIP) atau Individual

Total waktu: ~5 menit untuk 100 sertifikat!

❓ TROUBLESHOOTING CEPAT:

Q: "Python tidak dikenali"
A: Install Python, centang "Add Python to PATH"

Q: "Port 5000 sudah digunakan"
A: Edit app.py, ganti port=5000 → port=5001

Q: "File tidak bisa diupload"
A: File terlalu besar (max 500MB), upload dalam batch

Lihat README.md untuk troubleshooting lengkap.

🔧 PERSIAPAN SISTEM:

A. INSTALL PYTHON

   Windows:
   1. Download Python dari: https://www.python.org/downloads/
   2. Klik installer yang sudah di-download
   3. ⚠️  PENTING: Centang "Add Python to PATH" di halaman pertama!
   4. Klik "Install Now"
   5. Tunggu hingga selesai
   6. Restart komputer (recommended)

   Mac:
   1. Buka Terminal (Applications → Utilities → Terminal)
   2. Install Homebrew (jika belum):
      /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   3. Install Python:
      brew install python3

   Linux (Ubuntu/Debian):
   1. Buka Terminal
   2. Update package list:
      sudo apt update
   3. Install Python:
      sudo apt install python3 python3-pip

B. VERIFIKASI INSTALASI PYTHON

   Windows:
   1. Buka Command Prompt (tekan Win+R, ketik cmd, Enter)
   2. Ketik: python --version
   3. Harus muncul: Python 3.x.x

   Mac/Linux:
   1. Buka Terminal
   2. Ketik: python3 --version
   3. Harus muncul: Python 3.x.x

❌ TROUBLESHOOTING:

PROBLEM: "Python tidak dikenali sebagai perintah internal atau eksternal"
SOLUSI:
  1. Install ulang Python
  2. PASTIKAN centang "Add Python to PATH"
  3. Restart komputer
  4. Coba lagi

PROBLEM: "pip tidak dikenali"
SOLUSI:
  1. Sama seperti di atas, install ulang Python
  2. Atau jalankan: python -m pip install -r requirements.txt

PROBLEM: "ModuleNotFoundError: No module named 'pandas'"
SOLUSI:
  1. Jalankan: pip install -r requirements.txt
  2. Atau: pip install pandas openpyxl python-pptx pillow requests

PROBLEM: "PermissionError" atau "Access Denied"
SOLUSI:
  1. Tutup PowerPoint jika sedang terbuka
  2. Tutup file Excel jika sedang terbuka
  3. Jalankan Command Prompt sebagai Administrator (klik kanan → Run as Admin)

PROBLEM: Download foto sangat lambat atau banyak yang gagal
SOLUSI:
  1. Cek koneksi internet
  2. Tutup aplikasi yang menggunakan bandwidth (Netflix, YouTube, dll)
  3. Jalankan ulang script (foto yang sudah terdownload akan di-skip)
  4. Gunakan koneksi internet yang lebih stabil

PROBLEM: "Excel file not found"
SOLUSI:
  1. Pastikan file Excel ada di folder yang sama dengan script
  2. Nama file HARUS persis: Formulir_Lapor_Diri_Mahasiswa_PPG_2025_Batch_3.xlsx
  3. Jangan rename atau pindahkan file

PROBLEM: PowerPoint terlalu besar / tidak bisa dibuka
SOLUSI:
  1. File PowerPoint normal berukuran 500MB - 1GB
  2. Gunakan PowerPoint 2016 atau lebih baru
  3. Jika tetap tidak bisa, compress foto terlebih dahulu

PROBLEM: Script berhenti tiba-tiba
SOLUSI:
  1. Screenshot error message yang muncul
  2. Jalankan ulang script
  3. Jika tetap error, lihat error message dan cari solusinya
